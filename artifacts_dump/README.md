# artifacts_dump

This directory contains a frozen snapshot of experimental artifacts
generated by the OntologyRAG pipeline.

Contents include:
- retrieval outputs for all evaluated methods
- blind LLM-as-judge payloads and prompts
- LLM-as-judge outputs (including tie and skipped-identical cases)
- aggregated evaluation reports

No additional LLM-as-judge inference is planned for this snapshot.
These artifacts are preserved for inspection, reproducibility,
and discussion purposes.
